App bar
SpendlyTopBar
TopAppBar with a title and a single trailing search IconButton. Tapping it opens a full-screen search scoped to transactions — merchant, amount, category. One action only, matching the FAB's "one primary action" rule.
TopAppBar actions = IconButton(Search) surface bg
Removed
Category filter chip row
Cut from the homescreen. It was Tier 3 content placed high "for discoverability," but it did the same job as the new search action — finding spend by category. Filtering now lives in the Transactions tab where the full list already exists. Removing it also frees the row where the savings goal card now sits, keeping above-the-fold content within Miller's 7±2 limit.
Tier 1 · hero
MonthSummaryCard
Unchanged — monthly total, budget progress bar, MoM delta chip, day-pace text. Still the 4 guaranteed above-the-fold data points. Background primaryContainer, text onPrimaryContainer.
primaryContainer #EADDFF corner 20.dp
New · conditional
SavingsGoalCard
Renders only if the user has set a monthly savings goal in Settings. One row: target label, thin progress bar, percent complete. Sits directly below the hero as a positive counterpart to "budget remaining" — saving framed as progress, not restriction. Uses surfaceVariant bg with the success custom color for the fill.
if (goal != null) surfaceVariant #E7E0EC success #2E7D32
Tier 2 · scan
RecentTransactionCard
Unchanged — top 3 SMS-detected transactions grouped by date. "View all" routes to Transactions. Debit amounts use the expense color extension (= error).
New · conditional
UpcomingSubscriptionCard
Detects recurring SMS charges — same merchant, similar amount, roughly monthly cadence — and surfaces the next one if it falls within a 7-day window. Shows merchant, days until renewal, and last-known amount. Disappears once the charge actually posts and becomes a normal transaction row. Cap at one card: if several are due, show only the nearest and let "View all" list the rest.
if (daysUntilRenewal <= 7) show nearest only secondaryContainer icon
Updated
WeeklySpendSummary
Previously a bare sparkline with no labels. Now leads with the weekly total and a "vs last week" delta — same red/green logic as the monthly chip (increase = error, decrease = success). The 7-day bar chart below has the day of week as its x-axis label under each bar, with today's bar in solid primary to anchor the read. Still non-interactive; tap routes to Analytics.
x-axis = day labels header = total + delta Canvas composable
Tier 2 · conditional
OverBudgetAlertCard
Unchanged — renders only when a category exceeds its budget. errorContainer bg, onErrorContainer text, progress bar in error.
Tier 3 · scroll-reveal
BehavioralNudgeCard
Unchanged — one weekly insight, max one card, hidden when nothing's notable. tertiaryContainer bg.
Priority rule
Conditional card cap
With goal, subscription, overspend alert, and nudge all now possible, cap visible conditional cards at 2 per visit to keep cognitive load flat. Suggested priority when more are eligible: overspend alert, then subscription due, then nudge, then savings goal — the goal card is the gentlest, so it's first to drop.
